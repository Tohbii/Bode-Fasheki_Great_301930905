# MIT 8103 — Advanced Database Systems

## Project Overview

This repository contains my practical portfolio for the MIT 8103 Advanced Database Systems course at Miva Open University.

The portfolio demonstrates practical knowledge of relational database design, query optimisation, transaction management, NoSQL data modelling, and distributed and cloud database concepts.

## Case Study: Fashek Store

Fashek Store is a retail business used as the consistent case study across all five portfolio components.

The database models customers, products, orders, order items, and payments. The case study provides a practical context for exploring database design, data integrity, performance, transactions, document databases, and distributed database architecture.

## Portfolio Components

1. **Database Design and Modelling** — Relational schema design, ER modelling, normalisation, constraints, and implementation.
2. **Query Processing and Optimisation** — Query execution plans, indexing, and performance analysis.
3. **Transactions and Concurrency** — Transaction control, COMMIT, ROLLBACK, isolation levels, and concurrency behaviour.
4. **NoSQL and Advanced Data Models** — MongoDB document modelling, CRUD operations, embedding, referencing, and aggregation.
5. **Distributed and Cloud Database Exercise** — MongoDB Atlas deployment, replica set inspection, replication, read/write concerns, consistency, availability, and sharding concepts.
